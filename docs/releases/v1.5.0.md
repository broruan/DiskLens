# DiskLens 1.5.0

[English](#english) · [简体中文](#简体中文)

## English

See allocated disk space while expanding the directory hierarchy in Space explorer.

- **One expandable view:** directory names, allocated-space bars and sizes share the same rows. Expanding a directory reveals its children with their own usage bars; logical sizes and file counts remain available.
- **Every visible entry:** the full-width tree replaces the separate chart of the largest eight entries. Directory expansion, double-click navigation, Home folder, parent/root controls, search and CSV export remain available.
- **Clear percentages:** each entry's share uses its immediate parent's allocated bytes. Search does not renormalize the remaining rows. Directory metadata also uses blocks, so child percentages need not add up to 100%.
- **Honest incomplete results:** pending, partial and excluded-entry states stay visible. Exact percentages are omitted when the entry or its parent has incomplete measurements.

### Install or update

Choose the DEB matching **Ubuntu 22.04 / 24.04 / 26.04** and **amd64 / arm64**. For Ubuntu 22.04 on Intel/AMD x86-64:

```bash
sha256sum --ignore-missing --check SHA256SUMS
sudo apt install ./disklens_1.5.0_ubuntu22.04_amd64.deb
```

The release workflow runs tests, package validation and read-only UI checks on all six native targets before publishing six DEBs and `SHA256SUMS`. See the exact tag's workflow run and validation record for observed results. Automated/offscreen checks do not establish physical desktop or GPU behavior.

## 简体中文

空间分析将实际占用进度条合并到目录层级中，展开目录的同时即可查看子项的磁盘使用量。

- **同一棵可展开目录树：** 名称、实际占用进度条与大小放在同一行，展开目录后各子项也直接显示占用；逻辑大小与文件数继续保留。
- **不再受独立图表前八项限制：** 统一目录树占满内容区，保留按需展开、双击进入、主目录、上一级/根目录导航、搜索及 CSV 导出。
- **明确占比口径：** 每项以直属父目录的实际占用为分母，搜索后不重新归一化；目录自身元数据也占空间，因此子项占比不一定合计为 100%。
- **保留不完整统计状态：** 待统计、部分统计及排除项继续明确标注；条目或父目录尚未完整统计时，不显示精确百分比。
