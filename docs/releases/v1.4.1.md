# DiskLens 1.4.1

[English](#english) · [简体中文](#简体中文)

## English

Fixes missing folders in Space Analysis when a large subtree exhausts the scan budget.

- Immediate entries are listed before descending, preserving already-listed siblings when the budget runs out. Hidden files, empty folders, symbolic links, special files and hard-link aliases remain visible.
- Pending folders display their status instead of a misleading zero. Double-click a pending or incompletely listed folder to analyze it with a fresh budget; partial totals use `≥`.
- **Home folder** returns to your home directory. **Up one level** can move beyond the current scan root. Changing scope clears old search filters.
- Directory CSV reports include `state` and `children_complete`, so incomplete or excluded measurements are distinguishable from empty files.
- Scanning remains read-only. Symbolic links are not followed, hard links are counted once, and mounted directories can be analyzed separately. Count/depth limits remain; a single directory larger than the limit can still have an incomplete listing.

### Install or update

Choose the DEB matching **Ubuntu 22.04 / 24.04 / 26.04** and **amd64 / arm64**. For Ubuntu 22.04 on Intel/AMD x86-64:

```bash
sha256sum --ignore-missing --check SHA256SUMS
sudo apt install ./disklens_1.4.1_ubuntu22.04_amd64.deb
```

Local verification includes the regression that previously showed only one of four sibling entries, pending-folder navigation, parent-scope filter reset, CSV states, and a read-only comparison against a real home folder: 75 immediate entries, 75 visible, zero missing. The native release jobs run all 13 CTest targets and package/UI checks before publishing. Offscreen checks do not establish physical desktop/GPU performance.

## 简体中文

修复空间分析中大子目录耗尽扫描额度后，同级文件夹消失、看起来只有 Documents 等少数项目的问题。

- 先列出当前层项目，再深入子目录，达到扫描上限后保留已经列出的兄弟目录；隐藏文件、空目录、符号链接、特殊文件和硬链接别名均可见。
- 未扫描目录显示“待统计”，不再误显示为零。双击待统计或尚未列全的目录可继续分析；部分统计用 `≥` 标识。
- 新增“主目录”按钮；“上一级”可越过当前扫描根；切换范围时清空旧搜索，避免内容被旧条件隐藏。
- 目录 CSV 增加 `state` 和 `children_complete`，区分不完整统计、排除项与空文件。
- 继续采用只读扫描，不跟随符号链接，硬链接只计一次；挂载目录可单独打开分析。仍保留数量和深度上限，单个目录的直属条目超过上限时也会标为部分结果。

### 安装或更新

提供 **Ubuntu 22.04 / 24.04 / 26.04 × amd64 / arm64** 六种安装包，请同时匹配系统版本和架构。以 Ubuntu 22.04 的 Intel/AMD x86-64 为例：

```bash
sha256sum --ignore-missing --check SHA256SUMS
sudo apt install ./disklens_1.4.1_ubuntu22.04_amd64.deb
```

本地验证覆盖原先“四个同级项目只显示一个”的回归场景、待统计目录继续扫描、上一级清除筛选及 CSV 状态，并只读核对实际主目录：75 个顶层项目全部可见，遗漏 0 项。各原生发布任务会运行全部 13 个 CTest 目标及安装包、界面检查后再发布。离屏检查不代表实体桌面或 GPU 性能验证。
