# DiskLens 1.4.0

[English](#english) · [简体中文](#简体中文)

## English

A refreshed workspace and faster everyday navigation for the local Ubuntu storage explorer. This release includes the UI update previously available only on the main branch.

### What's changed

- Light sidebar, dark disk-usage card, clearer secondary text, and consistent buttons, tables and scrollbars.
- Overview cards reflow on narrower windows and at larger font sizes. Disk charts, rankings and table columns scale to keep values readable.
- Search updates are combined while typing; Enter applies immediately and clearing restores results immediately. Reused icons are cached, and tables and directory trees scroll by pixels.
- `Ctrl+F` focuses the current search; `Alt+1`–`Alt+6` switch pages; `F5` refreshes the current view. On Overview, `Ctrl+F` opens installed-app search.
- Refreshing Large files now repeats the scan. Enter in its directory field also starts scanning. Inventory progress no longer moves the page content when it appears or disappears.
- Existing cache whole-row/Space selection, readable selection colors, cleanup confirmation and protected uninstall previews remain available.

### Install or update

Six native DEBs cover **Ubuntu 22.04 / 24.04 / 26.04 × amd64 / arm64**. Choose the file matching both your Ubuntu version and CPU architecture. `amd64` is for Intel/AMD x86-64; `arm64` is for AArch64.

For Ubuntu 24.04 x86-64, download `disklens_1.4.0_ubuntu24.04_amd64.deb` and `SHA256SUMS` from this release, then run:

```bash
sha256sum --ignore-missing --check SHA256SUMS
sudo apt install ./disklens_1.4.0_ubuntu24.04_amd64.deb
disklens
```

The native release jobs build and test each package, check metadata and dependencies, install the DEB, and run read-only UI checks before publishing. The suite contains 13 CTest targets, including keyboard/search workflows, responsive layouts and production-style cache selection. Local UI validation also covers all seven pages in both languages at 13 and 18 px. Offscreen checks do not establish physical desktop/GPU performance or real uninstall behavior.

## 简体中文

本次正式发布新版界面与操作优化，包含此前仅推送到 main 分支、尚未进入安装包的改动。

### 更新内容

- 浅色侧栏、深蓝磁盘概览卡，提高辅助文字对比度，统一按钮、表格和滚动条。
- 首页卡片随窗口宽度及字号重排；磁盘环图、排行和表格列宽适配大字号，保持数值可读。
- 合并连续输入后的搜索更新，回车立即筛选、清空立即恢复。缓存重复绘制的图标，表格与目录树支持像素滚动。
- `Ctrl+F` 定位当前搜索，`Alt+1`–`Alt+6` 切换页面，`F5` 刷新当前视图；在总览页按 `Ctrl+F` 会打开软件搜索。
- 修复大文件页刷新未重新扫描的问题，目录输入框支持回车开始；软件信息加载进度显示或隐藏时，页面内容保持原位。
- 保留缓存整行/空格勾选、选中文字可读性、清理确认和受保护的卸载预览。

### 安装或更新

提供 **Ubuntu 22.04 / 24.04 / 26.04 × amd64 / arm64** 六种原生安装包。请同时匹配 Ubuntu 版本和 CPU 架构：Intel/AMD 的 x86-64 选择 `amd64`，AArch64 选择 `arm64`。

以 Ubuntu 24.04 x86-64 为例，下载本页的 `disklens_1.4.0_ubuntu24.04_amd64.deb` 与 `SHA256SUMS`，在同一目录执行：

```bash
sha256sum --ignore-missing --check SHA256SUMS
sudo apt install ./disklens_1.4.0_ubuntu24.04_amd64.deb
disklens
```

各原生发布任务先编译和测试，再检查安装包元数据及依赖、安装 DEB 并执行只读界面检查，全部成功后才发布。完整测试包含 13 个 CTest 目标，覆盖快捷键、搜索、自适应布局及正式样式下的缓存勾选。本地界面检查还覆盖七类页面的中英文及 13/18 px 字号。离屏检查不代表实体桌面/GPU 性能或真实卸载验证。
